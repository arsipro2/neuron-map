## Более свободная автоматическая раскладка

- Увеличено целевое расстояние между связанными узлами с 3,05 до 4,1 единицы.
- Усилено разделение соседних узлов без прямой связи, чтобы ветки было проще различать.
- Ослаблено стягивание к центру; карта остаётся компактной.
- Физика перетаскивания использует тот же масштаб расстояний.

Новая раскладка применяется по кнопке **Auto layout** в настройках. Её можно отменить через **Undo**.

Установщики для Ubuntu, Windows и macOS и файл контрольных сумм `SHA256SUMS` находятся во вложениях релиза.
