## Прозрачная иконка приложения

- Убраны чёрное поле и сплошная подложка вокруг сети.
- Узлы и связи сохранены по центру на прозрачном фоне.
- Обновлены PNG для Linux, ICO для Windows и ICNS для macOS.

Исходная иконка с прозрачностью находится в `src-tauri/icons/icon-source.png`.

Установщики: Ubuntu x64 (DEB/AppImage), Windows x64 (автономный EXE), macOS Intel / Apple Silicon (Universal DMG). Контрольные суммы — в `SHA256SUMS`.
