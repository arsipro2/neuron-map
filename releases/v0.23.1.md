# Neuron Map 0.23.1

- Show neighbors opens a persistent working neighborhood: the selected note and its current neighbors stay visible along with every new note created in this view, including deeper branches.
- Creating notes, navigating, editing, deleting links, and Undo/Redo keep the rest of the map hidden. Deleting the starting note also keeps the neighborhood active.
- Search is limited to this neighborhood. Show all notes returns to the complete map from either the editor or the graph banner.
- All notes remain in the same workspace and are saved/exported together. Switching workspaces or reopening the app starts with the full map.
