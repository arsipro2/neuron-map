## Открытие вложений

- Нажатие на имя вложения в установленном Neuron Map открывает файл в программе по умолчанию для Windows, Ubuntu или macOS.
- «Save a copy» сохраняет копию в выбранную папку. «Preview» по-прежнему показывает PDF и изображения внутри Neuron Map.
- Повторное открытие создаёт отдельную копию и не перезаписывает файл, который уже открыт в редакторе.
- Ошибка открытия отображается рядом со вложением; можно повторить попытку или сохранить файл вручную.

Открывается копия вложения. Чтобы сохранить внешние изменения в заметке, прикрепите отредактированный файл заново. Неактивные копии старше семи дней очищаются при следующем открытии вложения. Для постоянной копии используйте «Save a copy».

## Установка

- Ubuntu x64: DEB или AppImage.
- Windows x64: EXE с автономным установщиком WebView2.
- macOS Intel / Apple Silicon: Universal DMG.
- `SHA256SUMS` содержит контрольные суммы установщиков.

Приложение работает локально, без сервера разработки. Формат базы и идентификатор приложения сохранены. Подпись издателя и нотариализация macOS в этой сборке не настроены.
