# Neuron Map 0.24.0

- Open **Diagram** from a note's Content header to work in a large offline diagram window.
- Add rectangles, rounded rectangles, ellipses, diamonds and text. Move and resize shapes; choose fill, outline, text color, font size and line width.
- Connect shapes with straight or orthogonal connectors, optional arrowheads and labels. Connectors follow moved and resized shapes.
- Pan, zoom, fit the canvas, snap to a grid, select multiple shapes, duplicate, copy/paste, delete, Undo and Redo.
- Save editable diagrams inside their notes without changing the note text. Saved revisions participate in graph Undo/Redo, Trash, snapshots, and workspace export/import.
- Export diagrams as SVG or PNG. Unsaved changes prompt before closing the editor or desktop window; storage failures retain edits for retry.

This is Neuron Map's built-in diagram editor, not an embedded diagrams.net service. It does not import or export the `.drawio` / mxGraph format. Each note currently has one diagram; up to 500 shapes and 1000 connectors.
